Reposición y Pérdidas

Consultá qué mercadería necesita reponerse, revisá las pérdidas registradas y registrá una baja justificada. Las pérdidas modifican el inventario y quedan en el historial.

Necesidades de reposición

Estas cantidades son sugerencias de reposición. Revisalas antes de generar una compra.

Cómo reponer existencias

La reposición muestra necesidades. El ingreso real de mercadería se hace en «Compras y lotes», indicando proveedor, insumo, cantidad y costo. Así se generan los lotes y movimientos correspondientes.

Si lo que necesitás es corregir una diferencia de un conteo físico, utilizá «Ajustes y verificación»; no registres una compra ficticia.

Registrar pérdida

Esta operación descuenta existencias y deja trazabilidad del responsable y del motivo. Usá una base de datos de desarrollo para la prueba.
